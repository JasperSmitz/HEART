# HEART

An exploration of a personal AI assistant for natural-language tasks, starting with a terminal experience on Linux and macOS. The repository currently contains project documentation and agent workflow configuration; application implementation and a technology stack remain undecided.

Start with the [vision](docs/VISION.md), [current state and architecture questions](docs/ARCHITECTURE.md), and [roadmap](docs/ROADMAP.md). [AGENTS.md](AGENTS.md) defines the architect/developer/reviewer workflow. [Plans](docs/plans/README.md), [decisions](docs/decisions/README.md), and [lessons](docs/LESSONS.md) preserve approved scope and project learning.

The project agent configuration requires a compatible Codex version, locally trusted project access, and support for the requested models and reasoning levels. See [configuration and verification guidance](docs/ARCHITECTURE.md#agent-configuration); defaults may require a new session and do not prove an active runtime selection. No application setup is required yet.
