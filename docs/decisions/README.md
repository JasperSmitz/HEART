# Decisions

Create a numbered, descriptive Markdown record for a significant architecture or product decision. Do not turn exploratory ideas into decisions.

Include: status (proposed, accepted, superseded, or rejected), context, meaningful options, decision, consequences and tradeoffs, and user involvement/approval. Link relevant plans and any superseding record. Preserve the rationale when a decision changes.
