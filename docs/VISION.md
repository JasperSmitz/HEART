# Vision

HEART is an exploration of a personal AI assistant that helps a person carry out tasks expressed in natural language. The initial direction is a terminal experience on Linux and macOS, with capabilities that can grow in small, modular steps.

Its conversational interface serves short, useful interactions. Extended chatbot conversation is not the primary purpose: ordinary requests should usually receive a single-sentence answer. A friendly character and customizable speech styles should make those interactions inviting without adding verbosity or noticeable delay. A personalized home or dashboard and module-specific richer results remain future possibilities.

Interchangeable local and cloud models are a direction to investigate. Providers, integration mechanisms, and the extent of interchangeability remain undecided. The project should make deliberate choices based on useful tasks, user control, and practical constraints.

A desktop companion, including a possible KDE experience, is a long-term aspiration. These directions describe intent, not implemented features or delivery promises. The next discussion should identify core responsibilities and one useful, thin vertical milestone before application implementation is approved.
