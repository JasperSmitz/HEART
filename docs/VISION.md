# Vision

HEART is a personal, cozy terminal workspace on Linux and macOS: a welcoming home for useful tools, custom modules, and a character companion. It is a personal playground first, with a future path for others to create modules, themes, and characters. It surrounds existing terminal tools rather than replacing Ghostty, zsh, or the desktop environment.

Its conversational interface serves short, useful interactions. Extended chatbot conversation is not the primary purpose: ordinary requests should usually receive a single-sentence answer. A friendly character and customizable speech styles should make those interactions inviting without adding verbosity or noticeable delay. A personalized home or dashboard and module-specific richer results remain future possibilities.

Interchangeable local and cloud models are a direction to investigate. Providers, integration mechanisms, and the extent of interchangeability remain undecided. The project should make deliberate choices based on useful tasks, user control, and practical constraints.

A real embedded shell, persistent module widgets, dedicated module interfaces, character-specific artwork/themes, and JRPG-inspired dialogue are the evolving direction. [Pastel's terminal home](plans/0013-terminal-home.md) establishes the visual foundation. The [single manual embedded terminal](plans/0014-embedded-terminal.md) makes shell work the primary dashboard experience, with compact companion dialogue alongside it. Multiple shells, workspace management and new integrations require separate milestones. The assistant has no autonomous shell control.

A desktop companion, including a possible KDE experience, remains a long-term aspiration. Future directions describe intent, not implemented features or delivery promises; approved plans define each implementation's scope.
